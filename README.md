# 📚 LibraTech - Library Management System

Modern and responsive web application for complete library management.

## ✨ Features
- 📊 Dashboard with statistics
- 📖 Books management (CRUD)
- 👥 Members management
- ⚙️ Settings and notifications
- 📱 100% responsive design

## 🛠️ Technologies
- React 18
- Tailwind CSS
- Lucide Icons
- Vite

## 🚀 Installation
```bash
npm install
npm run dev
```

## 📸 Preview
Modern interface with sidebar, search, and adaptive mobile/desktop design.
